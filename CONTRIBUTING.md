# Contributing

Help improve connection instructions, examples, wording and reproducible setup reports.

- For installation problems, use the connection issue form and include the client version and the step that failed.
- For a useful scenario or documentation change, open an issue or pull request with the expected outcome.
- Keep claims within the exposed MCP tools and current capabilities. Distinguish module configuration from member moderation.
- Preserve the brand spelling Qreate.
- Do not attach access tokens, passwords, raw authorization logs, private server contents or Qreate's server implementation.

This is a documentation and discovery repository. Qreate's application source is not hosted here. General product support is available at https://discord.gg/qreate.
